# dot-globe

Reusable React point-cloud globe. See `README.md` for usage and development.

- Keep all repository content in English.
- Never inspect or copy third-party implementations; only generic visible behavior may inform design.
- Natural Earth 1:10m physical data is the geographic source of truth.
- Map correctness overrides visual matching.
- Run `pnpm check` and browser visual QA before completion.
